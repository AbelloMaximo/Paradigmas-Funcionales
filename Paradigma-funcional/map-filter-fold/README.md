#  Transformaciones de Colecciones (Map, filter y Fold) aqui se ven las tres operaciones fundamentales de para procesar colecciones de datos de forma declarativa en lugar de usar bucles 'for' imperativos.

# -Map: Transforma cada elemento de una colección aplicando una función.
# -Filter: Filtra una colección evaluando una condicion booleana para cada elemento.
# -Fold: Reduce toda la colección a un unico valor acumulativo combinando sus elementos paso a paso.
