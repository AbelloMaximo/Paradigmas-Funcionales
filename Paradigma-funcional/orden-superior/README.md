# Funciones como valores y Funciones de orden superior estas como su nombre dice explora como tratar a las funciones como ciudadanos de primera clase (pueden asignarse a variables, pasarse como argumentos y devolverse).

# -Funciones como valores: Las funciones pueden almacenarse en variables o ser pasadas dinámicamente.
# -Funciones de orden superior: Son funciones que reciben a otras funciones como parametros o devuelven la funcion como resultado.
# -Expresión Lambda: Funciones anónimas de una sola linea de ideales para operaciones rapidas.
