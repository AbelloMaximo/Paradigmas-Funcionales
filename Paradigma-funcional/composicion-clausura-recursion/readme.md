# La composicion de funciones clausura y recursion aqui se abrdan tecnicas avanzadas para combinar lógica y remplazar bucles tradicionales por estructuras funcionales.

- # Composicion de funciones:Consta de encadenar el resultado de una función como la entrada de otra (\(f(g(x)\)))
- # Clausuras: Funciones internas que rsuerdan y tienen acceso a las variables de su ambito lexico superior incluso cuando este ya ah finalizado.
- # Recursion: Tecnica donde una función se llama a si misma para resolver problemas iterativos (como el calculo de factoriales) sin alterar estados mutables.
