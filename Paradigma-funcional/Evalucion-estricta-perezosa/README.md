# Evalucion estrita y perezosa aqui se compara la gestion de memoria tradicional fente a la evaluación perezosa utilizando generadores de Python.

# Evaluacuión estricta: Calcula y almacena todos los elementos de una colección en memria RAM de golpe.
# Evaluación perezosa: Calcula los elementos únicamente cuando se lo solicitan mediante el uso de generdors ('yield'), optimizando drásticamente los recursos del sistema con grandes volumenes de datos.
