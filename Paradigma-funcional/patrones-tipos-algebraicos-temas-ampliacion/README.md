# Coincidencia de patrones y Tipos Algebraicos esto explora caracteristicas modernas de Python para modelar datos de manera segura y elegante.

# -Tipos Algebraicos de Datos (ADT): Modelado de estructuras de datos mediante la combinación de tipos (`Union` y `Dataclasses`).
# -Coincidencia de Patrones (Pattern Matching): Uso de la estructura `match-case` para desacoplar datos de forma limpia y legible, emulando la programación funcional avanzada. 

## Cómo ejecutarlo
Abre tu terminal en esta carpeta y ejecuta:
\`\`\`bash
python main.py
\`\`\`
El script te pedirá ingresar una figura geométrica y su medida para calcular el área mediante *Pattern Matching*.
